# Playbook

Folder ini dipakai untuk menyimpan setup trading yang sudah jelas aturannya.

## Isi Playbook
Setiap setup harus punya:
- Kondisi market
- Area entry
- Alasan valid
- Letak stop loss
- Target profit
- RR minimal
- Contoh chart valid
- Contoh chart tidak valid

## Catatan
Kalau setup belum masuk playbook, maka setup itu belum layak ditradingkan dengan serius.
