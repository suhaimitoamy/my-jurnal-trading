# Weekly Reviews

Folder ini dipakai untuk review mingguan.

## Fokus Review Mingguan
- Total trade minggu ini
- Setup terbaik
- Kesalahan paling sering
- Kepatuhan terhadap risk management
- Kondisi psikologis saat trading
- Rencana perbaikan minggu depan

## Aturan Penamaan
Gunakan format seperti:
- `2026-week-13-review.md`
