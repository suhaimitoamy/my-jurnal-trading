PDF materials for Learning Hub

Taruh file PDF di folder ini agar otomatis terbaca di Learning Hub.

Contoh:
- docs/assets/materials/market-structure-basic.pdf
- docs/assets/materials/risk-management-notes.pdf

Cara upload paling aman saat ini:
- buka Learning Hub
- klik tombol Upload PDF
- upload file ke folder ini lewat GitHub web
