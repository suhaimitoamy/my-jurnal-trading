# Screenshot Folder Guide

Taruh screenshot jurnal di folder berikut:

```text
docs/assets/images/screenshots/hari-xx/
```

Contoh:

```text
docs/assets/images/screenshots/hari-34/setup.png
docs/assets/images/screenshots/hari-34/entry.png
docs/assets/images/screenshots/hari-34/result.png
```

Catatan:
- Gunakan nama folder sesuai hari jurnal, misalnya `hari-34`
- Format gambar yang didukung: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`
- Reader akan mencoba memuat semua gambar di folder hari yang sesuai secara otomatis
