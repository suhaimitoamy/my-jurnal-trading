      Cara pakai singkat

      1. Buka Reader untuk membaca jurnal langsung di website.
      2. Buka Learning Hub untuk melihat materi pembelajaran yang diturunkan dari jurnal.
      3. Pakai Quick Access untuk buka rule, checklist, dan playbook penting.
      4. Gunakan Journal Builder setelah sesi selesai.
      5. Copy atau download markdown hasil draft, lalu simpan ke folder trades/ di repo GitHub.
