# My Jurnal Trading

Repo ini adalah pusat dokumentasi proses trading saya.
Tujuan utamanya bukan mengejar sinyal, tetapi membangun disiplin, evaluasi, perlindungan modal, dan sistem belajar yang bisa dipakai berulang.

## Fungsi Repo
- mencatat setiap trade dengan rapi
- menjaga konsistensi risk management
- memisahkan analisa, eksekusi, dan evaluasi
- mengurangi entry impulsif
- membangun data performa pribadi
- menyimpan playbook trading yang benar-benar bisa diuji

## Struktur Repo
### Fondasi
- `risk-management.md` -> aturan perlindungan modal
- `pre-entry-checklist.md` -> checklist wajib sebelum entry
- `journal-template.md` -> template jurnal untuk setiap trade
- `postmortem-template.md` -> template evaluasi setelah trade selesai

### Folder utama
- `trades/` -> jurnal harian per trade / per hari trading
- `weekly-reviews/` -> review mingguan, phase review, dan diagnosis besar
- `playbook/` -> metode inti, aturan tetap, checklist eksekusi, dan template review
- `screenshots/` -> tempat simpan chart sebelum dan sesudah entry

## Isi Penting yang Sudah Ada
### Di folder `playbook/`
- `core-method.md` -> metode inti trading
- `non-negotiable-rules.md` -> aturan yang tidak boleh dilanggar
- `execution-checklist.md` -> checklist sebelum entry
- `daily-review-template.md` -> template evaluasi setelah sesi trading

### Di folder `weekly-reviews/`
- `phase-review-day-31-to-35.md` -> review fase untuk hari 31 sampai 35
- `master-diagnosis-day-1-to-35.md` -> diagnosis besar perjalanan hari 1 sampai 35

### Di folder `trades/`
- jurnal hasil konversi yang sudah masuk repo
- `conversion-status.md` -> status progres konversi jurnal

## Aturan Inti
1. Capital preservation di atas segalanya
2. Tidak entry tanpa alasan yang tertulis
3. Tidak melanggar risk per trade
4. Tidak trading saat emosi tidak stabil
5. Setiap loss wajib dievaluasi
6. Tidak boleh ada trade tanpa stop loss
7. Tidak boleh mengikuti sinyal luar untuk eksekusi live

## Cara Pakai
1. Baca `risk-management.md` sebelum mulai trading
2. Gunakan `pre-entry-checklist.md` atau `playbook/execution-checklist.md` sebelum entry
3. Salin `journal-template.md` untuk trade / hari baru
4. Setelah sesi selesai, gunakan `postmortem-template.md` atau `playbook/daily-review-template.md`
5. Review pola kesalahan di folder `weekly-reviews/`
6. Perbarui playbook jika metode sudah benar-benar teruji

## Prinsip Utama
Trading yang baik bukan soal sering entry.
Trading yang baik adalah mampu menjaga modal, mengeksekusi rencana, lalu belajar dari hasil dengan jujur.

Repo ini bukan sekadar tempat menulis pengalaman.
Repo ini adalah operating system trading pribadi.
