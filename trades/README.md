# Trades

Folder ini dipakai untuk menyimpan jurnal setiap trade.

## Aturan Penamaan
Gunakan format nama file yang rapi, misalnya:
- `2026-03-29-eurusd-sell.md`
- `2026-03-30-gbpusd-buy.md`

## Cara Pakai
- Salin isi dari `journal-template.md`
- Buat 1 file untuk 1 trade
- Isi sebelum, saat, dan setelah trade selesai
