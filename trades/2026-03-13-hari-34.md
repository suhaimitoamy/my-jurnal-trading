## Insight Penting Hari Ini
Hari ini saya mulai memahami perbedaan antara Liquidity Sweep dan Liquidity Run, serta bagaimana menggunakannya dalam eksekusi trading.

### Rule yang Dipelajari
#### Liquidity Sweep
- Terjadi saat harga mengambil liquidity (PDL / swing).
- Setelah itu harus ada displacement kuat.
- Kemudian break swing terdekat.
- Struktur: Liquidity sweep -> Displacement -> Break swing -> Valid reversal
- Jika tidak ada break swing, maka itu bukan sweep.

#### Liquidity Run
- Jika harga break liquidity
- Tidak ada displacement reversal
- Tidak break swing lawan
- Maka kemungkinan besar itu continuation / liquidity run
- Struktur: Break liquidity -> Tidak ada break swing lawan -> Continuation trend
